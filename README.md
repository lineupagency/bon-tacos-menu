# Bon Tacos – menu

QR menu for Bon Tacos, plac Dominikański 3, Wrocław. Static page served by GitHub Pages.

- `index.html`: the whole menu (data, styles and script inline)
- `img/`: 1200×900 WebP product photos

Edit prices or items in the `MENU` array inside `index.html`, then commit and push. Pages republishes automatically.
